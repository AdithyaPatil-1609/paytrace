# PayTrace walkthrough

Start the live app using the root README. Verify the header reads **Reading Neo4j**. To record the walkthrough, install the Playwright Chromium browser and run `npm run demo` in another terminal. The recorder writes the video and numbered screenshots to `work/demo/`.

1. Open **All payments**, select Spotify and expand **Linked evidence** to show the price-rise finding.
2. Select **Simulate a new Autopay** to show the additional payment and yearly estimate. Reset the simulation.
3. In **Issues**, show the charge history. For an interactive example, try a matching price notice and compare it with an older notice under **More demo checks**.
4. Open **Cancel paths** to show the steps for both the service and payment provider. Open **Annual** to show the estimated cost.
5. Finish on **Evidence graph**. Select Spotify, inspect a record and expand **Explore live Neo4j queries and findings** to view the underlying Cypher.
